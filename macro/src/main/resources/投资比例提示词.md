# 理论

债券、股票、货币和商品这四大类资产的周期性轮动规律，通常被统称为‌大类资产配置周期‌。其核心理论框架是基于宏观经济阶段的变化，来指导不同资产的配置优先级。
历史上，最著名且被广泛引用的模型是‌美林投资时钟‌（Merrill Lynch Investment
Clock）。该模型由美国美林证券在2004年提出，将经济周期划分为四个阶段：‌衰退、复苏、过热、滞胀‌，并为每个阶段指明了最优配置的资产类别‌。
‌衰退阶段‌：经济下行，通胀下行。此时‌债券‌表现最佳，因为央行通常会降息刺激经济，债券价格上升；‌现金‌是良好的避险选择；股票和大宗商品表现较差。
‌复苏阶段‌：经济上行，通胀下行。‌股票‌成为最佳选择，企业盈利改善推动股价上涨；‌大宗商品‌开始显现潜力；债券收益下降，现金回报最低。
‌过热阶段‌：经济上行，通胀上行。‌大宗商品‌表现最突出，因需求旺盛和通胀预期；‌股票‌仍具韧性，但估值承压；‌现金‌和‌债券‌因通胀和加息预期而表现不佳。
‌滞胀阶段‌：经济下行，通胀上行。‌现金‌是相对最优选择，能抵御通胀；‌债券‌和‌股票‌因经济低迷与高通胀双重打压而表现糟糕；‌大宗商品‌可能因供应滞后而短暂坚挺，但最终面临需求回落压力‌。
